# NOTICE / Attribution / Disclaimer

## Что это
`atj2273sdk` — **неофициальный, открытый** набор для сборки под SoC Actions ATJ2273S / ATJ2273B /
ATJ213x (Actions OS, «USDK»). Он собран как **аналог вендорских SDK `usdk227c`, `usdk213f`,
`USDK1100`** и родственных пакетов, и предназначен для исследования, ремонта и сборки
альтернативных прошивок/приложений (в т.ч. кастомного лаунчера).

## Происхождение материалов
- `sdk/` — дерево SDK Actions (`USDK1100`), получено из открытого репозитория
  **github.com/mcirsta/ActSDK** («SDK for Actions SOC devices running UCOS»).
  Включает вендорские заголовки, библиотеки, линкер-скрипты и примеры исходников.
- `reference/actsemi/` — из **github.com/uli/actsemi** (обратный AOS-API: таблица сисколлов).
- `docs/` — **наши собственные** результаты обратного анализа прошивки (формат LFI/FWU, карта
  флеша, шифрование, ABI приложений).
- `tools/`, `tables/`, `reference/launcher_skeleton/` — **наши собственные** утилиты и материалы.
- Прошивки/дампы устройств (`.bin`) в репозиторий **не включены**.
